# RC Transmitter Channel Configuration

Recommended standard AETR channel assignments:

- **Channel 1 (Aileron)**: Roll rate control
- **Channel 2 (Elevator)**: Pitch rate control
- **Channel 3 (Throttle)**: Collective thrust / vertical climb
- **Channel 4 (Rudder)**: Yaw rate control
- **Channel 5 (Flight Mode)**: 3-position switch (MANUAL, GUIDED, RTL)
- **Channel 6 (Arming Switch)**: 2-position safety disarm / arm toggle
- **Channel 7 (Payload Trigger)**: Momentary toggle switch for drop servo actuation

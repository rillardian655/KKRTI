# Pre-Flight and Arming Safety Verification Checklist

Conduct the following sequence prior to every flight test:

- [ ] Airframe physical inspection (propeller tightness, motor mount rigidity).
- [ ] Battery voltage verification (minimum 4.15V per cell under zero load).
- [ ] Telemetry radio antenna orientation and RSSI link verification.
- [ ] GPS 3D fix lock confirmed with minimum 10 satellites visible.
- [ ] Geofence boundaries active and correctly uploaded.
- [ ] Transmitter flight mode switch responsive (manual takeover verification).
- [ ] Flight arena clear of non-authorized personnel.

# Sensor Calibration and Health Checklist

Before conducting autonomous flight tests, ensure all onboard sensors are calibrated:

1. **IMU Accelerometer**: 6-axis orientation calibration level with horizon.
2. **Magnetometer / Compass**: Complete 3D spherical rotation dance away from large metal objects.
3. **Barometer**: Zero offset calibration at ground level before arming.
4. **Airspeed Sensor**: Zero wind pitot tube cover check before takeoff.

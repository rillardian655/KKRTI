# KRTI Division Missions Overview

This flight stack addresses common technical requirements across KRTI categories:

- **Vertical Take-Off and Landing (VTOL)**: Precision coordinate hovering, drop mechanism actuation, autonomous landing within circular target zones.
- **Technology Development (TD)**: Failsafe verification, live ground control station telemetry stream, dynamic geofence containment.
- **Fixed Wing (FW)**: Multi-waypoint aerial survey, altitude profile management, and survey grid generation.
